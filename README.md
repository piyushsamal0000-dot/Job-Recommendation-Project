# 🎯 AI Job Match Finder

An intelligent Machine Learning-powered web application that recommends the most suitable AI/ML job roles based on a user's skills, education, experience, and career preferences.

Built using **Python**, **Scikit-learn**, and **Streamlit**, this project demonstrates an end-to-end machine learning workflow—from data preprocessing and model training to deployment with an interactive frontend.

## 📌 Features

- 🔍 Predicts the most suitable AI/ML job profiles
- 💻 Interactive Streamlit web interface
- 🧠 Machine Learning-based recommendation system
- 📊 Displays confidence scores for predicted job roles
- 🏆 Shows Top 5 recommended career options
- 🎨 Clean, responsive dark-themed UI
- ⚡ Real-time predictions based on user inputs

---

## 🖥️ Frontend Preview

The application allows users to enter:

- Skills (Multi-select)
- Experience Level
- Education
- Employment Type
- Preferred Company Size

After submitting the information, the model predicts the best matching AI career paths and visualizes the confidence scores using an interactive horizontal bar chart.

Example recommendations include:

- Machine Learning Engineer
- Data Analyst
- ML Ops Engineer
- AI Specialist
- Deep Learning Engineer
